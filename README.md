# أحمد وائل بدر — LiftLog AI (خيار مجاني للتجربة)

نسخة ويب من LiftLog مع شات مرتبط بـ Gemini API عبر خادم Node.js. Google توفر فئة مجانية لبعض نماذج Gemini API، مع حدود استخدام وتغيّر الأهلية والتوفر حسب النموذج والحساب والمنطقة. راجع صفحة الأسعار الرسمية قبل الاستخدام: https://ai.google.dev/gemini-api/docs/pricing

## تشغيل محلي
1. ثبّت Node.js 20 أو أحدث.
2. فك ضغط ZIP وافتح Terminal داخل المجلد.
3. نفّذ `npm install`.
4. انسخ `.env.example` إلى `.env`.
5. احصل على مفتاح Gemini من https://aistudio.google.com/apikey ثم ضعه في `GEMINI_API_KEY` داخل `.env`.
6. نفّذ `npm start`.
7. افتح `http://localhost:3000`.

## نشر مجاني للتجربة على Render
1. ارفع ملفات المشروع إلى مستودع GitHub.
2. في Render أنشئ Web Service واربط المستودع، أو استخدم إعدادات `render.yaml`.
3. اختر Free إذا كان متاحًا في حسابك.
4. أضف `GEMINI_API_KEY` في Environment داخل Render، وليس في HTML أو GitHub.
5. انشر التطبيق وافتح رابط الموقع.

Render يقدم خدمات مجانية للتجربة، لكن الخدمة المجانية قد تنام عند عدم الاستخدام ولها حدود. راجع: https://render.com/docs/free
Gemini API له حدود للفئة المجانية، وقد تتغير؛ إذا وصلت للحد، انتظر إعادة الضبط أو استخدمه محليًا/غيّر المزود. لا تفترض أن الاستخدام مجاني بلا حدود.

## الأمان
- لا تضع المفتاح في `public/index.html` ولا ترسله في الدردشة.
- المفتاح الذي تم مشاركته سابقًا يجب إلغاؤه، ولا تستخدمه مرة أخرى.
- الفئة المجانية في Gemini API قد تستخدم البيانات لتحسين المنتجات بحسب شروطها؛ لا ترسل بيانات حساسة.
- بيانات التدريب محفوظة محليًا في المتصفح وليست متزامنة بين الأجهزة.

## المحتويات
- قوائم العضلات والتمارين وتسجيل المجموعات.
- سجل محلي ومقارنة حجم التمرين.
- شات يرسل رسالة وسياق تمرين محدودًا إلى الخادم ثم Gemini.
- تصدير سجل التمارين JSON.
